# Планировщик · версия 2.3 (GitHub Pages / Android PWA)

Статическое веб-приложение с задачами на день, привычками, большими целями и календарём. Можно установить на Android через Chrome и работать **офлайн после первого успешного открытия**.

## Публикация

1. Откройте репозиторий `aibekn02-ops/planner-app` на GitHub.
2. Загрузите **содержимое** архива в корень ветки `main`, сохраняя структуру папки `icons/` (ZIP-файл сам по себе не публикуется как сайт).
3. В GitHub откройте `Settings → Pages → Build and deployment → Source: Deploy from a branch`, выберите ветку `main`, папку `/(root)` и нажмите `Save`.
4. После успешной публикации адрес должен быть `https://aibekn02-ops.github.io/planner-app/`. Пока публикация не проверена, это лишь ожидаемый адрес.

## Установка Android

Откройте опубликованную ссылку **в Chrome**, затем меню ⋮ → `Установить приложение` или `Добавить на главный экран` (название пункта зависит от браузера). После первого открытия подождите завершения загрузки ресурсов и проверьте вход в режиме полёта. Для установки нужен HTTPS или localhost; открытие `index.html` двойным нажатием с диска недостаточно.

## Сохранение данных и перенос

Данные хранятся **локально в браузере** (`localStorage`, ключ `quiet-rhythm-v2`, чтобы не ломать уже существующие данные для того же сайта). Синхронизации между устройствами нет. Используйте кнопки `Сохранить копию` (JSON) и `Восстановить из файла` для переноса между доменами/устройствами. Импорт заменяет текущие данные после подтверждения. Сохранение резервной копии особенно важно перед очисткой данных браузера и переустановкой.

## Ограничения

- Напоминания в фоне/синхронизация пока не реализованы. Для гарантированных уведомлений вне открытого приложения потребуется отдельная архитектура с push/сервером или нативной Android-оболочкой.
- В некоторых браузерах не появляется кнопка установки внутри сайта; используйте меню браузера.
- Версия собрана заново на базе доступного `index.html` версии 2.1, так как байты ранее созданного `planner-v2.3-pwa.zip` из библиотеки оказались недоступны для загрузки. Поэтому это **восстановленный комплект 2.3**, а не побайтная копия прошлого архива.

## Локальный просмотр

В папке проекта: `python -m http.server 8765`. Затем открывать `http://localhost:8765/`. Для проверки PWA на телефоне требуется публичный HTTPS-сайт: доступ к локальному серверу по обычному LAN-IP не всегда позволяет установить PWA.
